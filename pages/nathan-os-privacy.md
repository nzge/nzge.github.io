# Privacy policy: nathan-os job-search

*Last updated: October 1, 2026*

[nathan-os job-search](https://nzge.github.io/pages/nathan-os.html) is a personal tool operated by one
person, Nathan Ge, for his own use. This policy explains how it handles Google user data.

## Who the data belongs to

The tool connects only to Google accounts owned by Nathan Ge. It does not collect data from any other
person's Google account, and there are no other users.

## Google user data the tool accesses

Through Google's OAuth permissions, the tool can access, for the account owner only:

- **Gmail:** message content and metadata, used to find job-related email and to create draft replies.
  The tool does not send email by itself.
- **Google Sheets, Drive, Calendar, and Docs:** the owner's own files and events, used to keep an
  application tracker and to organize job-search material.

## How the data is used

Google user data is used only to provide these features to the account owner. It is not used for
advertising, it is not sold, and it is not shared with anyone.

Email content and files may be shown to an AI assistant that the owner runs on his own computer (for
example Anthropic's Claude) solely so that it can sort mail, draft replies, and update the tracker on
the owner's behalf. The tool does not use Google user data to train or improve its own machine learning
models. Any other data handling by an AI assistant provider is governed by that provider's own terms.

## Storage and retention

OAuth credentials are stored encrypted on the owner's own computer. Application data is stored in the
owner's own files and spreadsheet. The tool does not send Google user data to any server operated by the
tool or by me. The owner can delete the data and revoke the tool's access at any time from the Google
Account permissions page (myaccount.google.com/permissions).

## Sharing

Google user data is not transferred to third parties, except as needed to operate on the owner's behalf
as described above, to comply with the law, or with the owner's explicit consent.

## Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
